`screenshot*` ignore rule matched source files. Restore the existing facade and
anchor the screenshot-output ignore rule at the repository root. This restores
an existing module; it adds no new Rust product functionality.

The dependency lock is updated to remove the six currently reported RustSec
vulnerabilities (RUSTSEC-2026-0204, -0258, -0118, -0119, -0285 and -0257).
The libp2p 0.57 update removes the affected Hickory 0.25 dependency branch.
Related lock updates also remove reported unsound and yanked dependencies.

warning for the transitive `paste 1.0.15` crate (RUSTSEC-2024-0436). This warning
is retained and is not an assertion that every dependency is risk-free.

CI now uses pinned checkout/toolchain/cache actions, read-only repository
permissions, a pinned cargo-audit installation, locked Cargo builds, bounded
jobs and cancellation of superseded runs. The audit reads the lockfile directly
and no longer requires permission to create GitHub checks through a separate
audit action.

Documentation retains `RUSTDOCFLAGS=-D warnings`. Duplicate root compatibility
binaries delegate documentation to their corresponding workspace packages;
broken or private intra-doc links and literal JSON return examples are fixed.

The additional Source validation workflow checks tracked source merge markers,
package syntax, declared PBLang entry files and published checksum lists. It is
not a substitute for the Rust workspace checks or runtime/device validation.

validation is recorded separately in the repair report. No subscription,
